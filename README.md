# BOUGA | بُؤجة

**Your personal digital memory.**

بُؤجة مكانك الذكي لجمع الروابط والمحتوى المهم وتنظيمه والرجوع إليه وقت ما تحتاجه.

## Build Android APK

1. افتح تبويب **Actions** في GitHub.
2. اختر **Build BOUGA APK** ثم **Run workflow**.
3. بعد نجاح البناء، نزّل artifact باسم **bouga-apk**.

> Package ID remains `com.hafeza.links` for now to preserve upgrade compatibility with existing installs.
